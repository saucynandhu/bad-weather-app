# 🌪️ Weather Fever Dream

Welcome to the **Weather Fever Dream** — the chaotic cousin of your traditional weather app. Expect pixel crimes, design atrocities, and a UX experience that screams, "Why is this happening?"

## 😵 What Is This?

This is not your clean, minimalist, Material Design weather app. This is:
- Fonts fighting each other.
- Colors clashing like titans.
- Weather icons that may or may not reflect actual weather.

## 🔧 Built With

- HTML
- CSS (poorly, on purpose)
- JavaScript
- A dash of regret
- A bunch of images of the internet (might be breaking copyright laws)
